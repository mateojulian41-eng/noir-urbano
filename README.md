# NOIR URBANO

E-commerce desarrollado para una marca de ropa urbana, diseñado para ofrecer una experiencia de compra moderna y optimizada para dispositivos móviles.

## Características

- Catálogo de productos
- Carrito de compras
- Integración de pagos con Wompi
- Diseño responsive
- Despliegue en Vercel
- Gestión de pedidos

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Node.js
- Git
- GitHub
- Vercel
